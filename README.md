# 书间 · 字帖

清新古风的个人字帖工具，纯静态网页，可直接部署到 GitHub Pages，无需安装依赖或构建。

## 功能

- 汉字、词句、段落、笔画四种模式，自动分页。
- 米字格、田字格、回米格、方格；调整格子、行距、页边距、页码和字体。
- 带声调拼音，可只标示范格或逐格标注；首字加深、描红数量与颜色、插入空行和空列。
- 汉字模式独立设置每行示范字和描红字数量，并逐格指定示范、描红或留白；行布局自动保存，应用于所有汉字。
- 笔画模式内置 27 个基本笔画（基本笔画、折画、钩画三组），笔画为真实楷书字形而非示意图，起收笔与折角保留原样。笔画库支持按名称、拼音全拼或首字母检索（如 `heng`、`hz`、`折`），缩略图为静态渲染（不做动画，保证每个笔画都完整可辨）；点击即可添加，每行可自定义字例、复制本行（按住 Alt 一次复制 5 行）、删除本行，同一笔画可重复添加多行。
- 词句与段落模式按「避头尾」拆行，标点不会落到行首；标点按书写规范画在格子左下角。
- 读取本机已安装字体，或导入 TTF、OTF、WOFF、WOFF2 字体文件；选过的本机字体缓存在浏览器中，刷新自动恢复。
- 笔画模式下「笔画大小 / 笔画偏移」与「字例大小 / 字例偏移」是两组独立滑块，互不影响。
- 自定义题签、姓名日期栏，自动保存本机设置。题签作为纸面上方的独立标题区，与姓名行之间留足空隙；字号 24–72 px 可调。
- 「固定顶部留白」开启时，题签填不填、留空与否都不会让下方格子上下跳动；关掉则按实际内容收紧。
- 顶部题词（静心印章、诗句）与「春日偶成 / 静夜思 / 山水清音 / 日常词语」快捷入口与页面标题同处一行，不额外占用纵向空间，仅作观赏与快捷入口；宽度不足 960 px 时自动折到标题下方一行。
- A4 全文打印或通过浏览器保存为 PDF；当前页导出 2 倍分辨率 PNG。

## GitHub Pages

1. 将本目录文件推送到 GitHub 仓库。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**，选择你的分支与 **/(root)**，保存。
4. 等待部署完成后访问 `https://你的用户名.github.io/仓库名/`。仓库名若为 `你的用户名.github.io`，访问域名根路径即可。

资源使用相对路径，兼容项目子路径。也可直接打开 `index.html` 使用；推荐通过静态服务器预览，例如 `python -m http.server 8080`。

## 资源与隐私

内容与设置仅保存在本机浏览器，不上传，也不会向第三方发起任何网络请求。拼音由上下文自动推断，多音字仍需自行核对。

笔画字形为构建期数据：`scripts/build-strokes.py` 从 [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data) 取得含该笔画的汉字，按笔序索引抽出轮廓与中线，生成 `stroke-glyphs.js`（27 笔约 17 KB）。数据上游为 [Make Me A Hanzi](https://github.com/skishore/makemeahanzi)，字形取自文鼎科技公开授权的字体，按 **Arphic Public License** 分发，许可全文见 `assets/licenses/ARPHICPL.TXT`。运行时只读取这一份内置数据，不联网、不加载笔画字体。

- [pinyin-pro](https://github.com/zh-lx/pinyin-pro)：MIT，提供拼音。
- [Lucide](https://lucide.dev/)：ISC，提供图标。
- [Ma Shan Zheng](https://github.com/google/fonts/tree/main/ofl/mashanzheng)：SIL Open Font License 1.1，提供毛笔字体（已转为 woff2，仅在选用「毛笔楷书」时按需加载）。
- [Make Me A Hanzi](https://github.com/skishore/makemeahanzi) / 文鼎科技：Arphic Public License，提供笔画轮廓与中线。

楷体优先使用系统 KaiTi / STKaiti，没有时使用随附毛笔字体。不同系统的宋体、黑体外观可能略有差异。打印选择 A4、100% 缩放并关闭浏览器页眉页脚；应用自带完整页边距。打印与 PNG 导出按 2 倍分辨率渲染（页数超过 8 页时降为 1.5 倍，避免同时驻留过多位图）。

读取已安装字体需要桌面 Chrome / Edge，通过 HTTPS（包括 GitHub Pages）或 localhost 访问，并在点击后允许浏览器的字体访问请求。不支持该接口或不授予权限时，仍可导入字体文件。字体文件仅保存在当前浏览器的 IndexedDB 中，不上传；清除站点数据会移除字体缓存。

汉字模式的“每行字样”中，数量输入会保留另一类字的现有位置，并使用空白格增减数量；数量上限取决于当前行剩余格数。选择“示范 / 描红 / 留白”后点击带编号的格子，可精确修改该位置；编号与纸上从左到右的格子一一对应。调整方格大小或页边距后，超出当前列数的位置会暂时隐藏，恢复列数时仍保留。汉字模式的空列由逐格留白设置，其他模式保留原来的空列与描红选项。

## 本地开发与测试

```bash
python -m http.server 8080        # 启动本地预览
pip install -r requirements.txt   # 安装测试依赖
python scripts/check.py http://127.0.0.1:8080
```

`scripts/check.py` 用 Playwright 驱动本机 Edge 做端到端回归，覆盖四种模式、分页、标点避头尾、笔画库检索与增删改（含 27 个缩略图全部出墨、悬停不改变像素）、笔画/字例两组滑块互不干扰、顶部题词带与上方题签（含字号、左对齐、题签留白固定不跳动）、字体导入与本机字体、PNG/打印分辨率、设置持久化和响应式布局。
